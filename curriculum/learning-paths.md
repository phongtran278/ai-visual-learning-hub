# Curriculum Map — hypothesis v0.1

**Not validated.** This is a proposed learning sequence, not a prescribed industry curriculum.

1. **Foundation:** brief translation, tool capabilities, prompt anatomy, reference literacy.
2. **Visual Control:** composition, casting/posing, camera, lighting/material, style.
3. **Critique & Iteration:** diagnose errors, change versus preserve, compare revisions.
4. **Creative Systems:** consistent multi-asset campaigns, production handoff, responsible practice.

## MVP pilot: six lessons (candidates)
1. From client request to measurable visual brief.
2. Subject, scene and style: writing explicit constraints.
3. Composition and negative space.
4. Character count, posing and spacing.
5. Diagnosing visual errors and targeted revision.
6. Production-ready delivery and provenance.

Each lesson must contain outcomes, prerequisites, evidence card, task, rubric, submission protocol, common failures, and model-specific caveats. Publication requires review of source claims.
