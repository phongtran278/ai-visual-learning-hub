# M01 — From Client Brief to Visual Direction

**Competency:** AV-01 · **Stages:** Understand → Apply → Create · **Status:** Pilot draft  
**Source anchors:** [Anthropic prompt engineering](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/overview), [OpenAI prompting](https://developers.openai.com/api/docs/guides/prompt-engineering), [UNESCO 2024](https://doi.org/10.54675/JKJB9835) (progression only).

## Problem scenario
A client asks: *"Create a premium 4:5 real-estate recruitment visual, five Vietnamese professionals, confident and natural, space for a headline, not a generic corporate group photo."* A vague prompt often leaves key constraints untested.

## Understand — read and diagnose
Annotate the scenario with: audience, communication goal, deliverable, subject requirements, visual constraints, exclusions and acceptance criteria.

**Submission:** annotated brief plus two explanations: which requirements are objectively testable, and which require human aesthetic judgment.

## Apply — turn brief into an executable specification
Write a brief with:
- Purpose: recruitment campaign, premium editorial tone.
- Format: vertical 4:5 with a reserved headline-safe area.
- Subjects: exactly five people, distinct readable poses, no props.
- Composition: intentionally spaced ensemble, no accidental occlusion.
- Constraints: realistic anatomy; no generated logo/text needed.
- Acceptance checks: count five; verify usable text space; identify any anatomical issues.

Generate at least one candidate in the learner's own tool, then compare against the checklist. Do not hide failed attempts.

**Submission:** visual brief, actual prompt, model/version, output and acceptance checklist.

## Create — transfer to a new brief
New scenario: *"A refined 20/10 appreciation visual for a real-estate brand; minimal illustration, no text, room for later layout."* Independently choose the visual direction, propose two alternative concepts, select one and justify constraints and trade-offs. Generate/revise if a tool is available; alternatively produce an annotated art-direction specification.

**Submission:** two concepts, selected brief, artifact or annotated direction, rationale and revision notes.

## Rubric (0/1/2 per stage)
- Understand: correctly separates goal, format, visual constraints and acceptance criteria.
- Apply: brief is testable and comparison reports failures honestly.
- Create: independently reconciles new constraints and justifies choices.

## Evidence note
Vendor prompting documentation supports specifying success criteria and evaluating outcomes; it does **not** prove this lesson improves learner performance. UNESCO supports the educational level terminology, not this specific real-estate assignment.

## Responsible practice
Use synthetic or consented reference images; avoid personal details and misleading endorsements. Do not publish learner work without consent.
