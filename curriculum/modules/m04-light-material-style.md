# M04 — Light, Material & Visual Style

**Competency:** AV-04 · **Status:** Pilot draft

**Understand:** Annotate reference images for key light direction, shadow softness, contrast, surface finish, palette and mood. Distinguish observable attributes from subjective adjectives such as "premium."

**Apply task:** Given a reference and a provided checklist (soft side light, natural skin texture, restrained palette, readable fabric), create and compare an output. Record where the result deviates.

**Create task:** Develop a coherent visual treatment for two related campaign assets; justify intentional differences across compositions while preserving visual identity.

**Evidence:** annotations, reference permissions, prompt/settings, outputs, comparison, style rationale and model/version. **Assessment:** [pilot rubric](../../framework/pilot-assessment-rubric-v0.1.md), 0/1/2 per stage.

**Source:** [Google image generation guide](https://ai.google.dev/gemini-api/docs/image-generation) for platform guidance. Photography/design-theory source review and learner evaluation remain open.
