# M06 — Critique & Iteration

**Competency:** AV-06 · **Status:** Pilot draft

**Understand:** Given two generated images and a brief, identify at least two observable deviations. Separate hard failures (count, format) from subjective preferences (mood).

**Apply task:** Choose the highest-impact failure; revise while trying to preserve already successful properties. Capture before/after and report whether the fix introduced regressions.

**Create task:** Design a repeatable review loop for a new campaign: criteria → generate → inspect → prioritize → revise → stop/hand off. Explain the stopping rule and when to use manual design tools.

**Evidence:** acceptance criteria, prompt/version, artifacts including failed revisions, critique table and stopping rationale. **Assessment:** [pilot rubric](../../framework/pilot-assessment-rubric-v0.1.md).

**Sources:** [Anthropic prompting](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/overview), [OpenAI prompting](https://developers.openai.com/api/docs/guides/prompt-engineering), [Amershi et al. (2019)](https://doi.org/10.1145/3290605.3300233). These provide rationale, not proof of this lesson's efficacy.
