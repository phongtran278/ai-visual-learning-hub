# M05 — Reference & Editing Literacy

**Competency:** AV-05 · **Status:** Pilot draft

**Understand:** Explain the difference between inspiration, reference, transformation and localized edit. Identify consent, rights and privacy questions; recognize model-specific editing limitations.

**Apply task:** Using a permitted image, request a localized change (for example, remove a prop while preserving composition). Document the intended edit and any unintended changes; do not assert pixel-perfect preservation.

**Create task:** Design a multi-step reference-to-edit workflow for a new brief. Include checkpoints for permission, visual consistency, change tracking and fallback to manual editing.

**Evidence:** permitted reference, intended-change specification, before/after artifacts, deviations, tool/version and provenance log. **Assessment:** [pilot rubric](../../framework/pilot-assessment-rubric-v0.1.md).

**Sources:** [OpenAI Images](https://help.openai.com/en/articles/11084440-images-in-chatgpt), [Google image guide](https://ai.google.dev/gemini-api/docs/image-generation), [NIST Generative AI Profile](https://doi.org/10.6028/NIST.AI.600-1). These do not replace rights clearance.
