# AI Visual Competency Framework — draft v0.1

**Status:** Proposed framework, NOT an international standard or vendor certification. Domains below require research and curriculum validation.

## Proposed domains
| ID | Competency | Observable performance |
|---|---|---|
| AV-01 | Visual brief translation | Express audience, intent, deliverables and constraints clearly |
| AV-02 | Composition and spatial control | Specify framing, hierarchy, perspective and negative space |
| AV-03 | Subject and character direction | Define count, identity cues, pose, interaction and consistency |
| AV-04 | Light, material and style | Describe and evaluate illumination, surface qualities and visual language |
| AV-05 | Reference literacy | Use references appropriately, distinguish inspiration from copying |
| AV-06 | Iteration and error diagnosis | Identify mismatches, prioritize fixes and preserve successful elements |
| AV-07 | Production readiness | Evaluate artifacts, layout integration, resolution and editing needs |
| AV-08 | Responsible and reproducible practice | Document provenance, limitations, rights, model and revisions |

## Provisional progression
1. **Execute:** complete a guided task.
2. **Explain:** justify choices and recognize tradeoffs.
3. **Diagnose:** find errors and select targeted corrections.
4. **Transfer:** apply principles across briefs/tools and document uncertainty.

This progression is a Hub design proposal; it is not attributed verbatim to UNESCO or any provider.

## Next validation tasks
Map each domain to sources; interview working designers; pilot assessments; revise overlapping domains; document inter-rater agreement.
