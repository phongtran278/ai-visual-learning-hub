# Assessment Rubric — draft v0.1

Use this **task-specific** rubric for an early composition exercise; do not present scores as standardized or validated.

## Example: five-person editorial composition
Each criterion scored 0–3: 0 absent/incorrect; 1 major errors; 2 mostly meets brief; 3 meets brief clearly.

| Criterion | Evidence to inspect |
|---|---|
| Subject count | Exactly five distinct people |
| Spacing | Deliberate separation; no unintended overlaps |
| Pose differentiation | Distinct readable poses |
| Perspective/anatomy | No major physical inconsistencies |
| Layout suitability | Usable negative space for headline |

Maximum 15 points. This is **not** an industry benchmark. Record image, brief, model, date, rater, notes and revision number. Evaluate improvement against the same task rubric; do not infer general mastery from one image.
