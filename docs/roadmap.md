# Roadmap — research-first

## Phase 0: Repository foundation
README, contribution process, source registry, evidence matrix, draft competency framework. **Not** a shipped learning product.

## Phase 1: Research & Curriculum Validation
Review original sources, extract claim-level evidence, add academic literature, interview designers, publish framework v0.2 with limitations.

## Phase 2: Learning prototype
Build one end-to-end lesson: brief → guided practice in learner's own AI tool → image upload → self/peer critique → revision history.

## Phase 3: Private beta
Pilot with a small designer cohort; evaluate completion, rubric reliability and pre/post improvement; publish findings including failures.

## Phase 4: Low-cost application
Only after validation: auth, lesson reader, prompt composer, progress and private submission storage. No in-app paid generation by default.

## Decision gates
Do not claim vendor endorsement, validated competency levels, or learning effectiveness without corresponding evidence.
