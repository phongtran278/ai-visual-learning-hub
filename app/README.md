# VISION / LAB — MVP

The first interactive web MVP is at the **repository root** (`src/`, `package.json`, `index.html`).

- Dashboard and 7-module learning-path overview.
- Fully interactive M01: Understand (quiz), Apply (brief + checklist), Create (concept transfer).
- Browser-local draft and progress persistence; no login, backend, or AI API.
- Accessible mobile navigation and reset confirmation.
- Research transparency with direct links to Hub crosswalk and UNESCO source.

Run `npm ci && npm run dev`. See [preview and deployment notes](../docs/vision-local-and-preview.md).

Other modules have curriculum documents but **are not interactive yet**. Completion is self-reported and not validated.
